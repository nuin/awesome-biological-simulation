# c302

> Generate a NeuroML 2 network of C. elegans neurons and muscle from connectome data, run it with jNeuroML and save the membrane potential traces.

Licence: MIT · [Source code](https://github.com/openworm/c302)

## What it simulates

c302 generates models of the C. elegans nervous system as NeuroML 2 files. It reads the worm's connectome (which neuron synapses onto which, and how many synapses) and writes a network description: a population of cells, the chemical and electrical synapses between them, optional muscle cells and the current inputs. A second file in the LEMS language says how long to run, which time step to use and which voltages to record.

The same connectome can be turned into models at several levels of detail, chosen by a parameter set. Some sets use simple integrate-and-fire cells. Others use single-compartment conductance-based cells with ion channels. The sets are named A, B, C, C0, C1, C2, D and others. The c302 paper describes this as a multiscale framework: the wiring stays the same while the cell model changes.

c302 does not run the simulation itself. It writes files that jNeuroML, pyNeuroML or NEURON then run. It is part of the OpenWorm project, which aims at a full body model of the worm.

## When to use it

Use c302 to get a connectome-based worm network that any NeuroML tool can run, for example a pharyngeal circuit, a forward-locomotion circuit or the whole 302-neuron nervous system.

- Use [NetPyNE](netpyne.md) when you write the cell and network rules yourself and want detailed morphologies.
- Use [Arbor](arbor.md) for large multi-compartment networks on many cores.
- Use [The Virtual Brain](tvb.md) for mammalian regional dynamics rather than a single-neuron wiring diagram.

## Install

The current release is 0.12.0 (PyPI and the GitHub release, both checked). It is a MIT-licensed Python package.

```
pip install c302
```

The README installs from a clone instead:

```
git clone https://github.com/openworm/c302.git
cd c302
pip install .
```

Either route installs pyNeuroML, which brings jNeuroML (a Java program), and the connectome readers. You need a Java runtime to run the generated models with jNeuroML. The README lists OpenJDK 19 and Graphviz for Linux, which the usage examples need. Install NEURON with `pip install neuron` to run models in NEURON. The README also notes that Windows users need Python 3.10 for the owmeta dependency, and that c302 runs without a full owmeta install.

There is no c302 package on conda-forge.

## Run the tested example

This recipe builds c302 in a container and runs the example below. It needs [Docker](https://docs.docker.com/get-docker/) and nothing else. It last ran on 2026-10-17 in 2.7 s.

1. Download [c302-recipe.tar.gz](https://biosimhub.pages.dev/guides/c302/c302-recipe.tar.gz) (Dockerfile, run_c302.py, run.sh).
2. Unpack it and run the script:

   ```sh
   tar -xzf c302-recipe.tar.gz
   cd c302
   sh run.sh
   ```

### Parameters

| Option | Meaning | Example value | Range |
|---|---|---|---|
| `--params` | c302 parameter set | A | A, B, C, C1 |
| `--duration` | Simulated time (ms) | 2000 | 500 to 6000 |
| `--dt` | Time step (ms) | 0.05 | 0.01 to 0.1 |

Ranges are the limits used for the example recipe; the program itself may accept more.


## A first run

The README's usage example 1a generates and runs a small network: two neurons and one muscle cell with stepped current inputs, using parameter set A.

```
python c302/c302_IClamp.py A
pynml examples/LEMS_c302_A_IClamp.xml
```

The first command writes `c302_A_IClamp.net.nml` and `LEMS_c302_A_IClamp.xml`. The second runs the simulation with pyNeuroML. In the source (`c302_IClamp.py`), the neurons ADAL and PVCL and the muscle MDR01 receive 800 ms current pulses of 1, 2, 3, 4, 5 and 6 pA, starting at 100 ms and then every 1000 ms, for 6000 ms in all.

The recipe's driver script calls the same `setup` function with a shorter default duration (2000 ms, so two pulses) and runs the LEMS file through the pyNeuroML Python interface without a display.

Adapted from <https://github.com/openworm/c302#usage-examples>.

## Reading the output

Two kinds of files come out. The first is the model description: the `.net.nml` file lists the cells (for example an integrate-and-fire cell type), the populations, the projections between them and the input lists. The second is the recorded data: the LEMS file defines `OutputFile` entries, so jNeuroML writes `c302_A_IClamp.dat` for the neurons and `c302_A_IClamp.muscles.dat` for the muscle. Each `.dat` file is a plain text table. The first column is time in seconds and each further column is the membrane potential of one cell, in volts.

The recipe adds `summary.csv` with the minimum, maximum, mean and final value of each trace. Read it as a check that cells move off their resting value when current arrives. The LEMS file also defines displays for the neurons and muscles that pyNeuroML would plot if a display were available.

## Pitfalls

- **Java is required.** pyNeuroML runs the model through jNeuroML, so a missing Java runtime is the first thing to check.
- **Parameter sets differ.** Sets A, B and C change the cell model, so the same wiring gives different voltages. Name the set when you report a result.
- **Generate before running.** The `examples/` folder in the repository holds pregenerated files. If you change the generator or its inputs, regenerate them before running.
- **Long full-network runs.** The full 302-neuron network (`LEMS_c302_C_Full.xml` in the README) is much larger than the two-neuron example.
- **owmeta is optional.** Warnings about owmeta not being installed are expected for the examples. The README says c302 runs without it.
- **Units.** Times in the LEMS file carry units (`6000ms`, `0.05ms`). The `.dat` output is in SI units, so convert before plotting in millivolts.
